# UI
Только отображение/редактирование состояния. Не считать бизнес-агрегаты в ImGui. Не добавлять Qt/wx/GTK. GUI: SDL3 + Dear ImGui + ImPlot.

Структура: `App.cpp` — только окно, трей, цикл событий и шапка; каждая вкладка — свой класс
(`TodayView`, `HistoryView`, `ReportView`, `SettingsView`). Данные истории читает
`ActivityDataCache` вне рендеринга кадра. Ресурсы SDL держи в `SdlPtr`/RAII-обёртках, а не
в сырых указателях с ручной очисткой на каждом пути ошибки.
