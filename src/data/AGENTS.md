# Data layer — Codex

- Сохранять совместимость таблицы `activity_records` и старых `.NET` ISO-8601/PascalCase settings.
- Миграции только идемпотентные: сначала недостающие колонки, затем backfill, затем индексы.
- `duration_seconds` — 64-битное значение (`std::int64_t` / `sqlite3_int64`), не сужать до `int`.
- `start_epoch_ms`/`end_epoch_ms` используются для диапазонных запросов; старые текстовые поля сохраняются для совместимости.
- Закрытый ActivityRecord + удаление crash-checkpoint должны быть одной SQLite-транзакцией.
- Не терять пользовательские настройки при I/O ошибке. Ошибка чтения файла и ошибка JSON — разные случаи.
- Все пути файлов/SQLite должны корректно работать с Unicode-путями Windows.
- После изменений запускать `tests/test_data.cpp` и общий `ctest`.
