PcActivityTracker — portable-версия для Windows x64
===================================================

Установка не требуется.

1. Распакуйте архив в любой каталог, доступный на запись
   (например, D:\Programs\PcActivityTracker или на флешку).
   Не распаковывайте в Program Files: там каталог программы обычно
   недоступен на запись обычному пользователю.

2. Запустите PcActivityTracker.exe

Где хранятся данные
-------------------

Рядом с программой, в подкаталоге data:

    data\activity_tracker.db    история активности (SQLite)
    data\settings.json          настройки

Экспорт истории и отчётов (history.csv, history.json, report.csv, report.json)
складывается туда же. Полный путь показывается в статусной строке приложения.

Чтобы перенести всё на другой компьютер, скопируйте каталог целиком вместе с data.

Файл portable.txt фиксирует этот режим явно. Если его удалить, приложение всё равно
продолжит использовать каталог data рядом с собой, пока туда можно писать.

Состав архива
-------------

    PcActivityTracker.exe     приложение
    SDL3.dll                  графический слой
    libgcc_s_seh-1.dll        runtime GCC
    libstdc++-6.dll           runtime C++
    libwinpthread-1.dll       runtime потоков
    portable.txt              признак portable-режима
    README.txt                этот файл

Требования
----------

Windows 10/11 x64. Дополнительные runtime от Microsoft не нужны:
приложение собрано под UCRT, который входит в состав системы.

Удаление
--------

Удалите каталог целиком. Реестр приложение трогает только при включённой
опции «Запускать вместе с системой» — она пишет одно значение в
HKCU\Software\Microsoft\Windows\CurrentVersion\Run. Выключите её перед удалением,
либо удалите значение PcActivityTracker вручную.
